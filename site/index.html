Reasoning Reliability · research programme

Can we find how a model will fail, see it inside the model, and fix it better than a generic patch?

Adya Srivastava, BITS Pilani. Design stage (v3, Nov 2026). Sister project: Same Score, Different Process.

Benchmarks collapse models into one accuracy number. Two models can score the same and still break in different ways: one loses state, another plans poorly, another retrieves the wrong familiar answer. This programme builds a repeatable pipeline: measure breaking points, localize an internal signal, intervene, and verify against strong baselines.

Why this is hard. Failures look random until you control difficulty and labels. Looking inside without a labelled failure is guessing.

What exists today. Perturbation suites, skill profiles, agent taxonomies, and mech-interp tools each cover one slice. Few connect the same labelled failure from behaviour to internals to a targeted fix.

What this adds. One generator stack with exact solvers, eight candidate root abilities with ladders, and a diagnose → localize → fix → verify loop meant to run on new open models.

Status, November 2026: design written into the repo. Generators, verifiers, and new experiments are not started. Stage 0 is a frontier ladder check. Interactive demos on this page are illustrative, not measured results. How you can help ↓

    What happens next
    
    
    Q1 draft first, then sign-off and build.
    
    
    
      
    Q1 (draft). State loss via UpdateLedger: which competitor wins (stale / neighbour / prior), and does the cause differ in read vs computed mode? Specs in research/protocols/state_loss/.
    
      
    0. Frontier check. Run L1–L3 ladders on current frontier models. If they do not break, extend the ladders.
    
      
    1. Measure. Generators, verifiers, QA, noise floor, profiles. Gates later work on RQ1.
    
      
    2. Predict. Hidden-family race. Reported checkpoint, not a hard stop.
    
      
    3–5. Localize, fix, verify, generalize. Probe pass bars are pre-registered. Targeted fix must beat matched, strong, and mismatch controls.
