## Source-management rule

Use [[templates/PAPER_NOTE]] when creating a detailed note for a paper. Record the exact paper version, sample and repeat counts, page/table/figure references, limitations, and how it changes our novelty assessment. The overview is a navigation and synthesis page; detailed claims should eventually be checked against the full paper.
