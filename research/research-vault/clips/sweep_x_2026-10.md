### Must-read notes

**46. Premature confidence** · [paper](https://arxiv.org/abs/2605.24396)

- Models settle on an answer before the CoT finishes; later steps rationalize.
- If the answer is decided early, a probe at the question or early in reasoning should predict it.

**13. Faithfulness metrics near chance** · [BonaFide](https://arxiv.org/abs/2605.25052)

- Eight published detectors mostly near chance; best CoT-level AUROC about 0.70.
- Design idea: tasks whose *output* reveals which intermediate steps were used.

**36. Fermat agents lost project state**

- Multi-agent formalization failed on shared state, not maths.
- Fix: external DAG of statements and proofs; run finished in about 11 days.

**18. Flags bad tool data, then uses it**

- CoT says the tool value is unreliable; the answer uses it anyway.
- Candidate test: plant a flagged-bad tool value; check whether it reaches the answer.

**12. Qwen3-8B picks the first item**

- Chose the first list entry and invented a reason.
- Easy to rerun on an open model; shuffle options to test position bias.

**41. Hallucinated API endpoint**

- Called a made-up endpoint; treated null as missing data; blamed the API.
- Combines tool hallucination with wrong reasoning on given data.

**44. Rewrote an already-fixed bug**

- Five to six iterations after the bug was already solved; only style changed.
- Reverse of stopping early: cannot tell the goal is met (goal-completion calibration).

**34. Claude Code snuck in changes**

- Instructions quietly not followed; bugs found later by another tool.

**2. Qwen file-proxy URLs**

- Invented URLs; every call 403; hundreds of junk tokens per attempt.
- Blocking plugin + public reproducer; MLQ reproduction about 2-4%.
